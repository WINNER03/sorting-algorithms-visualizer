# Sorting Algorithms Visualizer

An interactive, responsive JavaScript visualizer of five classic sorting algorithms, styled like a black-and-orange CS fundamentals infographic.

## Algorithms
- Bubble Sort
- Selection Sort
- Insertion Sort
- Merge Sort
- Quick Sort

## Features
- Animated sorting comparisons and swaps
- Play all algorithms or click an individual row
- Adjustable speed, reset, and shuffle
- Responsive dark-themed interface

## Run locally
Open `index.html` in any modern web browser. No dependencies or build step required.

## Deploy to Netlify
1. Go to [Netlify](https://app.netlify.com/) → **Add new project** → **Import an existing project** → **GitHub**.
2. Select **WINNER03/sorting-algorithms-visualizer**.
3. Leave **Build command** blank and use `.` as the **Publish directory**.
4. Click **Deploy**. New GitHub commits will redeploy the site automatically.

No environment variables needed.
